# Игра Камень, Ножницы, Бумага

Это простая игра "Камень, Ножницы, Бумага", написанная на JavaScript с минималистичным интерфейсом. Игра была создана мной как часть обучения основам программирования и веб-дизайна.

## Описание

- Пользователь выбирает один из трёх вариантов: Камень, Ножницы или Бумага, нажимая на соответствующую кнопку.
- Компьютер случайным образом выбирает свой вариант.
- Результаты раунда (победа, поражение или ничья) отображаются на странице.
- Игра длится до 5 очков: первый, кто наберёт 5, побеждает. После этого появляется кнопка "Новая игра".

## Структура файлов

- `index.html` — основной HTML-файл с разметкой игры.
- `styles.css` — файл стилей для минималистичного дизайна.
- `script.js` — JavaScript-файл с логикой игры.

## Как играть

1. Откройте `index.html` в браузере.
2. Нажмите одну из кнопок: "Камень", "Ножницы" или "Бумага".
3. Следите за результатами раундов и счётом на странице.
4. Играйте до 5 очков, затем начните заново с кнопки "Новая игра".
